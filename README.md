A loading-screen tip that makes a tired developer laugh and feel seen, written for the make.fun bounty.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Loading… the agent is reading the docs you skipped, the tests you never wrote, and the TODO you left in 2019.
```
